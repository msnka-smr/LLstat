# CS2 Stata

Статистика игровых сессий команды в CS2 на cybershoke.net: сводка за всё время и за последнюю сессию, рейтинг по формуле HLTV Rating 2.0.

Сайт: см. вкладку **Settings → Pages** репозитория или ссылку, закреплённую в описании репозитория.

Полное техзадание и обоснование решений — в [SPEC.md](./SPEC.md).

## Как обновить статистику после сессии

Два равноправных способа, можно чередовать.

### Способ 1: свои матчи по кукам

Работает, если сессию играл ты (под своим аккаунтом cybershoke). Нужно один раз положить сессионную куку в `.env`:

```
CYBERSHOKE_COOKIE="сюда кука из браузера"
```

**Как получить куку:**

1. Зайди на `cybershoke.net`, убедись, что залогинен.
2. Открой панель разработчика (`F12`), вкладка **Network**.
3. Обнови страницу (`F5`), в фильтре набери `api/v2/main/data`, кликни по строке.
4. Во вкладке **Headers** найди `Request Headers → cookie:` и скопируй всё значение целиком в `.env` как выше.

Кука рано или поздно протухнет — сборщик скажет об этом явной ошибкой, тогда повтори шаги выше.

Дальше — одна команда, она сама скачает новые матчи, пересчитает статистику, закоммитит и запушит:

```bash
npm run update
```

### Способ 2: ручная дозагрузка ссылками

Авторизация не нужна вообще. Подходит, если играл не ты, или кука протухла:

```bash
npm run add -- https://cybershoke.net/match/11836698 https://cybershoke.net/match/11836879
npm run add -- --file links.txt   # по одной ссылке/id на строку
```

Тоже сам закоммитит и запушит после сборки.

## Прочие команды

```bash
npm run collect   # только скачать новые матчи, без сборки/коммита
npm run build      # только пересобрать docs/data/stats.json из уже скачанных данных
npm test           # юнит-тесты (формула рейтинга, сессии, квалификация, сортировка...)
```

## Устройство репозитория

```
data/matches/<id_lobby>.json   сырые ответы cybershoke, один файл на лобби
data/config.json               костяк команды, пороги квалификации и цвета
data/players.json              ручные имена и история ников по steamid64
docs/index.html                сама страница
docs/data/stats.json           всё, что читает страница (пересобирается build'ом)
scripts/collect.mjs            сборщик матчей
scripts/build.mjs              агрегация и рейтинг
```

`data/config.json` стоит донастроить под себя:

- `coreSteamIds` — steamid64 вашей постоянной компании (влияет на то, какие матчи попадают в статистику).
- `qualifyShare` / `qualifyMinMaps` — плавающий порог квалификации в общем рейтинге.
- `colorThresholds` — где рейтинг красится в зелёный/жёлтый/красный.
