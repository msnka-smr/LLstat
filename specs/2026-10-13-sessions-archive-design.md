# Архив сессий — дизайн

Дата: 2026-10-13. Подпроект 1 из 4 (архив сессий → история рейтинга → рекорды → «Итоги вечера»).
Решения по ходу обсуждения с пользователем; `specs/` лежит вне `docs/`, чтобы не публиковаться на Pages.

## Цель

Сейчас сайт показывает только последнюю сессию (игровой вечер). Нужно открывать любую прошлую сессию на той же вкладке. Это фундамент для следующих подпроектов («Итоги вечера» будут строиться по выбранной сессии).

## Данные (`scripts/build.mjs` → `docs/data/stats.json`)

- Поле `lastSession` заменяется массивом `sessions` (от новой к старой). Дублирующей копии `lastSession` нет.
- Элемент `sessions[i]` имеет ту же форму, что `lastSession` сейчас:
  `id`, `firstPlayedAt`, `lastPlayedAt`, `maps[]` (`mapId`, `lobbyId`, `map`, `statsTier`, `teams`, `url`) и `players[]` (строки `buildRow`, рейтинг — `calcSessionRating` по картам этой сессии, сортировка по рейтингу по убыванию).
- Логика построения одной сессии выносится в отдельную функцию и вызывается для каждой сессии из `assignSessions`.
- `allTime.players[].ratingDelta` по-прежнему считается относительно последней сессии (`sessions[0]`).
- `isQualified` в строках сессий считается по текущему порогу квалификации, как и сейчас для последней.
- Размер `stats.json` вырастет примерно в 2–3 раза (сейчас 72 КБ, 38 карт) — допустимо.

## Страница (`docs/index.html`)

- Вкладка называется «Сессии». Внутренний id остаётся `lastSession` (совместимость с `llstat:selectedTab` в `localStorage`).
- Над таблицей — выпадающий список сессий; по умолчанию выбрана последняя. Подпись: «ДД.ММ.ГГГГ · N карт» (для `-2`, `-3` в тот же день различимо по порядку и числу карт).
- Выбранная сессия живёт в состоянии страницы; после перезагрузки открывается последняя.
- Заголовок сессии, таблица игроков, сортировка и колесо фортуны работают для выбранной сессии; колесо пересобирается при смене сессии. «Оправдалка» от сессии не зависит.
- Все обращения к `state.data.lastSession` заменяются на хелпер «текущая сессия».
- Если сессий нет — прежнее сообщение «Сессий пока нет.»; если сессия одна — список с единственным пунктом.

## Проверка

- Юнит-тест функции построения сессии/списка сессий (порядок «новая → старая», у каждой сессии свои игроки и карты).
- `npm test` остаётся зелёным (на момент спеки — 53 теста).
- Браузер (Edge через Playwright), 1280px и 375px: переключение между сессиями обновляет заголовок, таблицу и колесо; нет ошибок в консоли и горизонтального скролла; вкладки «За всё время» (бейдж `ratingDelta`) и «Карты» не сломаны.
- `npm run build` пересобирает `stats.json`; коммитит и пушит пользователь.

## Вне рамок

История рейтинга, рекорды, карточка «Итоги вечера» — отдельные подпроекты со своими спеками. Расположение их элементов на сайте обсуждается в их собственном дизайне.
