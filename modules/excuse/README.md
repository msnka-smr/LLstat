# Модуль «Оправдалка» (временно убрано с сайта)

Убрано из `docs/index.html` 2026-10-29 по просьбе владельца. Чтобы вернуть —
написать Claude «верни оправдалку» и сослаться на этот файл.

Что это: блок на вкладке «Сессии» (последний под «Картами вечера»): кнопка «Найти
оправдание» по очереди зажигает 3–5 случайных мемных отмазок CS2-игроков (с ✅) в
облаке-3D-сфере (спираль Фибоначчи, авто-вращение, перетаскивание с инерцией; при
`prefers-reduced-motion` без авто-вращения). От выбранной сессии не зависит.
Чтобы добавить фразу — дописать в массив `EXCUSES` в `excuse.js`.

## Файлы

- `excuse.css` — стили `.excuse-*` (включая мобильный `@media`).
- `excuse.js` — весь JS: `EXCUSES`, `excuseState`, `tickExcuseSphere`, `renderExcuseSection` и т.д.
- `index.before-removal.html` — полная копия страницы до удаления (эталон).

**Связь с «Итогами вечера»:** `modules/recap/recap.js` берёт «Шутку вечера» из
`EXCUSES` (`randomExcuse`). Если возвращать «Итоги вечера», «Оправдалку» (хотя бы
массив `EXCUSES`) нужно вернуть раньше или вместе с ними.

## Как вернуть (4 точки в docs/index.html)

1. CSS: вставить `excuse.css` перед правилом `.draft-section {`.
2. HTML: `<div id="excuseSection"></div>` после `<div id="sessionMapsSection"></div>`.
3. JS: вставить `excuse.js` перед комментарием «Гости (игроки со стороны)…».
4. В `render()` добавить `renderExcuseSection();` (например, после `renderSessionMapsSection();`).

После возврата: `npm test`, проверить вкладку «Сессии» на 1280px и 375px и обе
темы, убрать пометку в CLAUDE.md.
