# HANDOFF — как продолжить работу над cs2-stata с другого компьютера

Дата составления: 2026-11-11. Секретов (токенов, кук) в этом файле нет — только их названия.

## 1. Что это

Сайт «Рейтинг игроков "ЛЛ"»: статистика CS2-матчей друзей по API cybershoke.net.
Живой адрес: https://msnka-smr.github.io/LLstat/ , репозиторий: `msnka-smr/LLstat`.
Подробности устройства — в `CLAUDE.md` (главный файл для Claude), `SPEC.md`, `README.md`,
`specs/`, `plans/`, `modules/*/README.md`.
Есть второй, отдельный сайт `cs2statforLC` (друзья из LC party) — свой репозиторий `StatForLCparty`,
в этот архив он не входит.

## 2. Восстановление за 10 минут

1. Установить Git и Node.js (LTS). Войти в GitHub под аккаунтом владельца репозитория.
2. `git clone https://github.com/msnka-smr/LLstat.git cs2-stata`
3. `cd cs2-stata`, затем `npm test` (все тесты должны пройти) и `npm run build`.
4. Запустить Claude Code в этой папке — он прочитает `CLAUDE.md` и этот файл.
5. Для сбора матчей по куке создать `.env` (см. раздел 3). Без куки работает `npm run add -- <ссылки>`.

Ветки на GitHub: `master` (живой сайт), `redesign-glass` (редизайн, уже влит в master),
`telegram-bot`. Теги-страховки: `backup-before-redesign`, `backup-live-before-glass`.

## 3. Секреты — в репозитории их НЕТ, хранить в менеджере паролей

| Где | Имя | Что это / как получить заново |
|---|---|---|
| локально, файл `.env` | `CYBERSHOKE_COOKIE` | кука залогиненного cybershoke из браузера |
| локально, `bot/.dev.vars` | как у воркера | нужен только для локального запуска бота |
| GitHub → Settings → Secrets → Actions | `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | токен — у @BotFather (можно перевыпустить) |
| Cloudflare Worker `cs2-stata-bot` | `BOT_TOKEN`, `WEBHOOK_SECRET`, `GITHUB_TOKEN_DISPATCH`, `ALLOWED_CHAT_ID` | `npx wrangler secret put <ИМЯ>` в папке `bot/`; значения обратно не прочитать |

Аккаунты, к которым нужен доступ: GitHub (репозиторий), Cloudflare (воркер), Telegram (бот
`@cs2_stats_tracking_bot`). ID владельца в Telegram: 410675218 (не секрет). Воркер:
https://cs2-stata-bot.msnka-stata.workers.dev. Настройка бота с нуля — `bot/README.md`.

## 4. Как обновляется статистика

- Бот: владелец присылает ссылки на лобби → воркер запускает workflow `update-stats.yml` → коммит
  в master → явный запрос сборки Pages (последний шаг workflow) → сайт обновляется.
- Вручную: ярлык `update-stats.bat` (`npm run add -- --basic-if-pending --file …`) или Actions → Run workflow.
- Коммиты бота попадают только на GitHub: перед своей работой делать `git pull --rebase --autostash`.
- Тот же принцип у `set-matchday.yml` (вкладка MatchDay, пишет `docs/data/matchday.json`).

## 5. Правила и решения владельца (из заметок Claude)

- Статистика пока из лобби-API, без обогащения демками (решение 2026-10-02): у части карт нет демо-статов.
- Дизайн: эмодзи и грубый клипарт — «кринж». Использовать инлайн-SVG/CSS, цвета через CSS-переменные,
  проверять светлую и тёмную темы и телефон, варианты сначала показывать в браузере.
- При правке `docs/glass.css` ВСЕГДА увеличивать номер в `glass.css?v=N` в `docs/index.html`
  (сейчас `v=5`), иначе у посетителей держится кэш.
- Пушит владелец или явно разрешает каждый раз; Claude без разрешения не коммитит и не пушит.
- Убранные с сайта модули лежат в `modules/` (рулетка `wheel`, `recap`, `excuse`); вернуть — по README модуля.
- Рейтинг «за всё время»: шкала 0–5000, база 1000; «Сессии»: 1–1500. Ассисты и матрица убийств — только на «Сессиях».
- Мобильная вёрстка (2026-11-11): строка игрока `7 карт · K 176 - D 121 · K/D 1.45` собрана из
  неразрывных групп `.pm-g`; на «Выбор составов» ник сверху, рейтинг и K/D под ним. Проверялось на 320/360/390 px.

## 6. Открытые темы и планы

1. **Новогоднее оформление** — залить ~2026-12-10 (±). Макет утверждён 2026-11-05 (`newyear-final-d-ice.html`
   в папке `cs2-stata-newyear-mockups` рядом с проектом, не в репозитории — скопировать отдельно). Его надо
   адаптировать под стиль Glass. Вкладку «Итоги года» обсудить ~2026-12-17, публиковать в последнюю неделю
   декабря; отсчёт до 2027-01-01, в январе оформление убрать одной правкой.
2. **Фан-статистика из демок** (ADR, клатчи, OpenFrag и т. д.) — ON HOLD, кода нет. План: этап 1 проба
   `demoparser2` на одной демке и сверка с цифрами cybershoke; этап 2 конвейер `data/demo-stats/<id>.json`;
   этап 3 блок «Фан-статистика». Демки публичны: `https://cdn-de-1.cybershoke.net/demos/<id>?series=1`
   (~190 МБ). Лобби-API при частых запросах отдаёт 429.
3. **Редизайн Glass** — применён на сайте; макеты (`cs2-stata-redesign-mockups`) остались вне репозитория.
4. **Вариант «Сохранить турнир»** для cs2statforLC — отложенная идея (кнопка на сайте пишет в репозиторий через воркер бота).
5. Мелкие замечания по боту отложены, детали в `plans/2026-10-19-telegram-bot.md` (ledger).

## 7. Бэкапы

На прежнем ПК: задание Windows «CS2 Stata Backup», каждый четверг 11:30, zip папок `cs2-stata` и
`cs2statforLC` вместе с `.git` в `cs2-stata-backups\` (8 последних). В копии нет `.env`, `bot/.dev.vars`,
`node_modules`. Основная защита от потери — сам GitHub-репозиторий.

## 8. Что скопировать вручную, кроме репозитория

- Секреты из раздела 3 (из менеджера паролей).
- Папки макетов `cs2-stata-newyear-mockups` и `cs2-stata-redesign-mockups` (если нужны планы 1 и 3).
- Папку заметок Claude `C:\Users\<пользователь>\.claude\projects\...\memory\` — необязательно, главное
  из неё уже перенесено в этот файл.
