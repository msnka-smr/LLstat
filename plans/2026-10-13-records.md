# Рекорды и зал славы — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Добавить вкладку «Рекорды»: 15 рекордов в четырёх группах (личные за карту, серии, матчи, «Бывает с каждым»), у каждого топ-3 с контекстом и ссылкой на матч.

**Architecture:** Чистый модуль `scripts/lib/records.mjs` считает все рекорды по картам и сессиям (юнит-тесты), `build.mjs` пишет результат в `stats.json` полем `records`. Страница рисует новую вкладку карточками на ванильном JS (DOM через `textContent`), без библиотек.

**Tech Stack:** Node ≥ 20 (ESM, `node --test`), ванильный JS/HTML/CSS на странице без сборки; проверка в браузере — Playwright (`playwright-core`) + локальный Microsoft Edge.

**Spec:** `specs/2026-10-13-records-design.md`

## Global Constraints

- Язык интерфейса, комментариев и текстов — русский.
- Страница остаётся одним файлом `docs/index.html` на ванильном JS, без библиотек и сборки.
- Цвета и шрифты — только CSS-переменные сайта.
- Название группы «Бывает с каждым»; названия рекордов — ровно из спеки (мягкие формулировки в группе «Бывает с каждым» не менять на более резкие).
- Один игрок — одно место в топе личных рекордов и серий (его лучший результат); топ — не более 3 записей.
- Пороги: `MIN_KILLS_FOR_KD = 15`, `MIN_DEATHS_FOR_KD = 10`; серия — не короче 2.
- Равные значения: выше тот, кто достиг результата раньше (`playedAt`), затем стабильно по `mapId`/`steamid64`.
- Изменение `stats.json` — только добавление поля `records`; остальные поля не меняются.
- Данные игроков в DOM — только через `textContent`/атрибуты; ссылки — `target="_blank" rel="noopener"`, только `https://`.
- `npm test` остаётся зелёным (на момент плана — 72 теста).
- Коммиты — только по просьбе пользователя (правило CLAUDE.md), `git push` делает пользователь. Шаги «Commit» — готовая команда для пользователя.

## Review Focus

- Нет карт или нет сессий: все 15 рекордов с `top: []`, страница показывает «Пока нет» в карточках, без ошибок.
- Нет поля `records` в данных (старый файл): вкладка показывает «Рекордов пока нет.», без ошибок.
- Игрок с 5 убийствами и 0 смертей не занимает первое место в «Лучшем K/D» (порог 15 убийств); аналогично порог смертей у «Карта не задалась».
- Один игрок с несколькими лучшими картами занимает в топе одно место; равные значения упорядочены детерминированно.
- Имя игрока с HTML (`<img onerror=…>`) не превращается в DOM-элемент; на 375px нет горизонтального скролла; сохранённая вкладка `records` открывается после перезагрузки.

```js
// Вкладка "Рекорды": 15 рекордов в четырёх группах, у каждого топ-3.
// Личные рекорды и серии — один игрок на одно место (его лучший результат),
// матчевые — по картам. Равные значения: выше тот, кто достиг результата
// раньше (playedAt), затем стабильно по mapId/steamid64.
export const MIN_KILLS_FOR_KD = 15; // иначе 5/0 побеждал бы 30/10
export const MIN_DEATHS_FOR_KD = 10;
export const MIN_STREAK = 2;
export const TOP_N = 3;

const matchUrl = (lobbyId) => `https://cybershoke.net/match/${lobbyId}`;
const kdOf = (p) => (p.d > 0 ? p.k / p.d : p.k);
const round2 = (v) => Math.round(v * 100) / 100;

// a лучше b? rank сравниваем по dir ("desc" — больше лучше), затем раньше, затем по tie.
function better(a, b, dir) {
  if (a.rank !== b.rank) return dir === "desc" ? a.rank > b.rank : a.rank < b.rank;
  if (a.playedAt !== b.playedAt) return a.playedAt < b.playedAt;
  return String(a.tie) < String(b.tie);
}
function pickTop(candidates, dir) {
  return [...candidates]
    .sort((a, b) => (better(a, b, dir) ? -1 : better(b, a, dir) ? 1 : 0))
    .slice(0, TOP_N);
}
function bestPerPlayer(candidates, dir) {
  const best = new Map();
  for (const c of candidates) {
    const cur = best.get(c.steamid64);
    if (!cur || better(c, cur, dir)) best.set(c.steamid64, c);
  }
  return pickTop([...best.values()], dir);
}

// Все (карта, игрок) как кандидаты; value считает вызывающий.
function playerCandidates(maps, filter, rankOf) {
  const out = [];
  for (const m of maps) {
    for (const p of m.players) {
      if (!filter(p)) continue;
      out.push({
        steamid64: p.steamid64, rank: rankOf(p), playedAt: m.playedAt, tie: m.mapId,
        k: p.k, d: p.d, map: m.map, url: matchUrl(m.lobbyId),
      });
    }
  }
  return out;
}
function personalTop(maps, { filter = () => true, rankOf, dir, value = (c) => c.rank }) {
  return bestPerPlayer(playerCandidates(maps, filter, rankOf), dir).map((c) => ({
    steamid64: c.steamid64, value: value(c), k: c.k, d: c.d, map: c.map, playedAt: c.playedAt, url: c.url,
  }));
}

// Самая длинная серия подряд карт игрока, где predicate истинен (>= MIN_STREAK).
function longestRun(items, predicate) {
  let best = null;
  let start = null;
  items.forEach((it, i) => {
    if (predicate(it)) {
      if (start === null) start = i;
      const len = i - start + 1;
      if (len >= MIN_STREAK && (!best || len > best.len)) best = { len, from: items[start].playedAt, to: it.playedAt };
    } else {
      start = null;
    }
  });
  return best;
}
function streakTop(runsByPlayer) {
  const candidates = [];
  for (const [steamid64, run] of runsByPlayer) {
    if (run) candidates.push({ steamid64, rank: run.len, playedAt: run.to, tie: steamid64, run });
  }
  return bestPerPlayer(candidates, "desc").map((c) => ({
    steamid64: c.steamid64, value: c.run.len, from: c.run.from, to: c.run.to,
  }));
}

function matchTop(maps, { rankOf, dir }) {
  const candidates = [];
  for (const m of maps) {
    const [a, b] = (m.teams ?? []).map((t) => t.score);
    if (a == null || b == null) continue;
    const hi = Math.max(a, b);
    const lo = Math.min(a, b);
    candidates.push({
      rank: rankOf({ diff: hi - lo, rounds: m.totalRounds ?? hi + lo }),
      playedAt: m.playedAt, tie: m.mapId,
      entry: { map: m.map, score: [hi, lo], rounds: m.totalRounds ?? hi + lo, playedAt: m.playedAt, url: matchUrl(m.lobbyId) },
    });
  }
  return pickTop(candidates, dir).map((c) => c.entry);
}

export function computeRecords(maps, sessions) {
  // карты каждого игрока в хронологическом порядке
  const byPlayer = new Map();
  for (const m of maps) {
    for (const p of m.players) {
      const list = byPlayer.get(p.steamid64) ?? [];
      list.push({ ...p, playedAt: m.playedAt });
      byPlayer.set(p.steamid64, list);
    }
  }
  const runs = (predicate) =>
    streakTop(new Map([...byPlayer].map(([id, list]) => [id, longestRun(list, predicate)])));

  // сессии, в которых играл каждый игрок
  const attended = new Map();
  for (const s of sessions) {
    for (const m of s.maps) for (const p of m.players) {
      const set = attended.get(p.steamid64) ?? new Set();
      set.add(s.id);
      attended.set(p.steamid64, set);
    }
  }
  const attendanceRuns = new Map(
    [...attended].map(([id, set]) => [
      id,
      longestRun(sessions.map((s) => ({ playedAt: s.firstPlayedAt, played: set.has(s.id) })), (x) => x.played),
    ])
  );

  const kdValue = (c) => round2(c.rank);
  return [
    { id: "most-kills", group: "personal", title: "Больше всего убийств за карту", hint: "личный максимум за одну карту",
      top: personalTop(maps, { rankOf: (p) => p.k, dir: "desc" }) },
    { id: "best-kd-diff", group: "personal", title: "Лучшая разница K-D за карту", hint: "убийства минус смерти за одну карту",
      top: personalTop(maps, { rankOf: (p) => p.k - p.d, dir: "desc" }) },
    { id: "best-kd", group: "personal", title: "Лучший K/D за карту", hint: `минимум ${MIN_KILLS_FOR_KD} убийств на карте`,
      top: personalTop(maps, { filter: (p) => p.k >= MIN_KILLS_FOR_KD, rankOf: kdOf, dir: "desc", value: kdValue }) },
    { id: "carry-in-loss", group: "personal", title: "Тащил в проигрыше", hint: "лучшая разница K-D на проигранной карте",
      top: personalTop(maps, { filter: (p) => !p.won, rankOf: (p) => p.k - p.d, dir: "desc" }) },

    { id: "win-streak", group: "streaks", title: "Серия побед подряд", hint: "карт подряд; пропущенные игроком карты серию не рвут",
      top: runs((x) => x.won) },
    { id: "kd-streak", group: "streaks", title: "Серия карт с K/D не ниже 1.0", hint: "карт подряд",
      top: runs((x) => kdOf(x) >= 1) },
    { id: "attendance-streak", group: "streaks", title: "Железная посещаемость", hint: "игровых вечеров подряд",
      top: streakTop(attendanceRuns) },

    { id: "biggest-win", group: "matches", title: "Самый крупный разгром", hint: "наибольшая разница в счёте",
      top: matchTop(maps, { rankOf: (x) => x.diff, dir: "desc" }) },
    { id: "closest-match", group: "matches", title: "Самый упорный матч", hint: "наименьшая разница в счёте",
```

## Изменения после финального ревью (2026-10-13)

План выше описывает первую версию; после независимого ревью внесено (код и тесты — в репозитории, спека обновлена):

- Равные результаты делят место (`place`), в записи рекорда есть `more` — число не поместившихся в топ-3 с таким же результатом; на странице строка «и ещё N с таким же результатом». Причина: на реальных данных семь игроков имели одинаковую «Железную посещаемость», и показ трёх «случайных» выглядел несправедливо.
- Ничья и `won: null` — не победа и не поражение. «Трудная карта» — только отрицательная разница K-D, «Тащил в проигрыше» — только положительная. Порядок равных на одной карте — по `mapId:steamid64`.
- Страница: пустая карта/дата не дают «null»/«1970», явные ветки для `longest-map`/`shortest-map` и запасная ветка для неизвестного рекорда, сетка `minmax(min(300px, 100%), 1fr)`.
- Вкладка «Рекорды» стоит последней (после «Выбора составов») по просьбе пользователя; ряд вкладок на экране ≤ 520px переносится на вторую строку (пять вкладок ~430px в один ряд на телефоне не помещаются).
- Тестов: 90 → 103.
- Отложено (мелочи): подпись «игровых вечеров» при двух сессиях в один день; серия K/D при карте 0/0 считается разрывом.
