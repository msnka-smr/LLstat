# MatchDay: порядок карт и составы на вечер — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Вкладка «MatchDay» с датой сессии, двумя составами и «Маршрутом вечера» (7 карт), которые владелец закрепляет командами `/maps` и `/teams` через Telegram-бота; на «Выборе составов» появляются правка варианта состава и кнопка «Определить порядок карт».

**Architecture:** Чистый модуль `scripts/lib/matchday.mjs` разбирает и проверяет команды и сливает данные в `docs/data/matchday.json`; его используют и воркер бота (разбор команды), и новый workflow `set-matchday.yml` (повторная проверка и запись). Сайт читает `matchday.json` отдельным `fetch` и рисует вкладку на ванильном JS; команды для бота сайт только формирует и копирует, сам ничего не пишет.

**Tech Stack:** Node ≥ 20 (ESM, `node:test`), Cloudflare Worker (`bot/`), GitHub Actions, ванильный JS/HTML/CSS в `docs/index.html`, Playwright + локальный Edge для проверки страницы (см. `CLAUDE.md`).

**Spec:** `specs/2026-10-29-map-order-design.md`

## Global Constraints

- Пул карт ровно 7, в этом написании ключей: `de_mirage`, `de_dust2`, `de_inferno`, `de_nuke`, `de_ancient`, `de_anubis`, `de_cache`.
- Порядок вкладок: «За всё время», «Сессии», «Выбор составов», **MatchDay**, «Карты», «Рекорды» (id: `allTime`, `lastSession`, `draft`, `matchday`, `maps`, `records`). Подпись вкладки — «MatchDay» латиницей.
- Дата сессии вводится только как `ДД.ММ.ГГГГ` (с годом), хранится как `YYYY-MM-DD`, одна на весь MatchDay (`sessionDate` на верхнем уровне `matchday.json`); «сегодня» считается по Москве (UTC+3); сегодняшняя и будущие даты допустимы, прошедшие и несуществующие (`30.02.2026`) — ошибка.
- Команда без даты не меняет сохранённую дату; команда с датой заменяет её для всего MatchDay.
- Каждая команда боту закрепляет только свою часть (`maps` или `teams`), вторую не трогает; у каждой части свой `savedAt` (UTC ISO).
- Команда состава: ровно две команды по 5 человек, 10 разных; игрок из списка — `steamid64`, гость — имя (1–40 символов) и рейтинг 1–1500 (целое).
- Новых секретов нет; `GITHUB_TOKEN_DISPATCH` уже умеет Actions: Read and write. Публичная страница ничего в репозиторий не пишет.
- Файл `docs/data/matchday.json` не трогает `scripts/build.mjs`.
- Страница без сборки и без зависимостей; цвета только из CSS-переменных сайта; проверять 1280px и 375px без горизонтального скролла.
- Тексты для пользователя — по-русски, тон спокойный.
- Коммиты: русские сообщения в стиле репозитория, в конце строка `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. `git push` делает владелец.

## Review Focus

- `/maps` с 6 или 8 картами, повтором или картой вне пула (`train`) — ошибка, workflow не запускается. Тест в задаче 1 и в задаче 3.
- `/maps@cs2_stats_tracking_bot ...` (так Telegram дописывает имя бота в группах) разбирается как `/maps`. Тест в задаче 1.
- Дата без года (`31.10`), `30.02.2026`, вчерашняя дата — понятная ошибка, ничего не запускается. Тест в задаче 1.
- `/teams` с одним игроком в обеих командах, с командой не из 5 человек, с гостем без рейтинга или с рейтингом 0 / 1501 — ошибка. Тест в задаче 1.
- Закрепили карты, потом составы (и наоборот): первая часть и общая дата не пропадают. Тест в задаче 1.
- Имя гостя с запятой, `|`, `=`, `~` или эмодзи: команда, сформированная сайтом, обратно разбирается ботом в тех же людей. Проверка в задаче 6.
- `matchday.json` отсутствует (404): вкладка MatchDay показывает «Вечер пока не запланирован», в консоли нет ошибок. Проверка в задаче 4.
- `steamid64` из команды нет в `stats.json`: MatchDay показывает «неизвестный игрок», страница не падает. Проверка в задаче 5.
- Пул карт на сайте совпадает с пулом в `scripts/lib/matchday.mjs`. Тест в задаче 7.
